# Generated project images

36 individual PNG images generated from docs/project-image-sets.md using the built-in image_gen tool.

Each project has two landscape 1536 x 1024 images (display and wide) and two portrait 1024 x 1536 images (detail-a and detail-b). Original references are preserved in assets/all-projects/.

The manifest records references, prompt-file paths, output paths, generation status, dimensions, file sizes and SHA-256 hashes. Each image has a sibling .prompt.txt file containing its scene brief. Some generation prompts include additional screen-role and composition guidance.

These are generated presentation mockups. Fine text and QR codes are not guaranteed to reproduce source artwork exactly. Original screenshot test content and placeholder labels may remain visible.
