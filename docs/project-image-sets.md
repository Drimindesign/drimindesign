# Project image sets: one prompt per project (ChatGPT Images)

**How to use:** for each project, open a **new chat**, attach the files listed under it (from `assets/all-projects/`), paste that project's **one prompt**, and send. ChatGPT makes the four images one after another. If it stops early, reply **"continue with the next image"**. If it still puts them together in one collage, reply **"No collage. Make Image 1 only, as one full-frame image"**, then ask for each next image the same way ("Now Image 2 only, full-frame").

Save them as `<slug>-display.png`, `<slug>-wide.png`, `<slug>-detail-a.png` and `<slug>-detail-b.png`, then send them over to put on the site.

**What the four images are for:** 1 is the main picture (ring, Projects page, top of the project page). 2 is a wide picture of the work in real use. 3 and 4 are close-ups shown side by side.

**If a screen or website comes out with messy text:** reply *"redo image N with the screen left plain light grey"*, then place your real screenshot on that screen in Figma or Photoshop. For the main picture, upscale it 2× (e.g. the free Upscayl app) before sending.
