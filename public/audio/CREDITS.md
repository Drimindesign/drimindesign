# Game audio
Dialogue generated offline with Kokoro-82M (hexgrad, Apache-2.0), using kokoro-onnx (MIT).
https://huggingface.co/hexgrad/Kokoro-82M
https://github.com/thewh1teagle/kokoro-onnx
No cloned real-person voices. Regenerate with scripts/generate-orbit-voices.py.

Animal recordings (CC0), normalized and compressed:
- Dog Growl by bonebrah: https://opengameart.org/content/dog-growl
- Dog barking mono by Brandon Morris / HaelDB: https://opengameart.org/content/dog-barking-mono
Wolves use a pitch-shifted dog growl. Boar snorts remain procedural.

Music: Kevin MacLeod (incompetech.com), CC BY 4.0, as credited in the game.
